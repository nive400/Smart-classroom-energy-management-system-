# Smart-classroom-energy-management-system-
Smart Classroom Energy Management System

📖 Overview

The Smart Classroom Energy Management System is an Arduino-based project that reduces electricity wastage by automatically controlling classroom appliances. An IR sensor detects the presence of people entering or leaving the classroom, and the system switches lights and fans ON or OFF accordingly.

🎯 Objectives

- Minimize unnecessary energy consumption.
- Automate the operation of classroom appliances.
- Provide a simple, reliable, and cost-effective energy management solution.

✨ Features

- Automatic detection of occupancy using an IR sensor.
- Automatic control of lights and fans.
- Energy-efficient operation.
- Low-cost and easy-to-implement design.

🛠️ Technologies Used

- Arduino Uno
- Embedded C
- Arduino IDE

📦 Hardware Requirements

💻 Software Requirements

- Arduino IDE
- Embedded C

⚙️ Working

1. The IR sensor detects the presence of a person.
2. Arduino receives the sensor signal.
3. When a person is detected, the relay turns ON the classroom lights and fan.
4. When no person is detected for a specified time, the relay turns OFF the appliances, reducing energy consumption.
